1. Who We Are

Memory is an AI memory application designed to make AI assistants more relevant and personal by remembering context about you — transparently and under your full control. We operate under the principle that your memories belong to you, not us.

References to "Memory", "we", "us", or "our" in this policy refer to the Memory application and its operators.

2. Data We Collect

We collect only what is necessary to provide the Memory service:

  • Account information: Email address and authentication credentials (handled via Supabase Auth with JWT tokens — your password is never stored in plain text).
  • Memory content: Statements, preferences, and context that you explicitly choose to save or approve for storage.
  • Usage metadata: When a memory was created, last used, how many times it was referenced in answers.
  • Chat context: Conversation messages processed by the LLM API (Groq / Gemini) to detect possible memories. Chat messages are not permanently stored unless a memory is explicitly saved.
  • Device information: OS version, app version, and crash logs — used only for debugging.
We do not collect browsing history, location data, contact lists, biometric data, financial information, or any data unrelated to the memory service.

3. How We Use Your Data

Your data is used exclusively to:

  • Surface relevant memories when you interact with AI assistants
  • Show you your own memory activity in the Vault and Review Queue
  • Authenticate your account securely
  • Improve memory detection accuracy (anonymised, opt-in only)
  • Send you product-critical notifications (e.g. memory expiry warnings)

We do not use your data for advertising, profiling, or sale to third parties.

4. Data Storage & Security

Memory data is stored in a PostgreSQL database protected by Row Level Security (RLS). This means database-level enforcement ensures you can only ever access your own memories — not other users' data.

  • All data is encrypted in transit (TLS 1.3) and at rest (AES-256)
  • Authentication uses JWT tokens with short expiry windows
  • Sensitive memory details are masked by default (configurable in Privacy Center)
  • API secrets are stored as environment variables and never embedded in client code
  • Semantic search uses pgVector — embeddings are stored securely in the same RLS-protected database

5. AI Processing

Memory uses large language model APIs (Groq API and Gemini API) to detect possible memories from your conversations. When you chat:

  • Message content is sent to the LLM API over an encrypted connection
  • The API processes your message and returns a possible memory suggestion
  • Nothing is saved until you explicitly approve it
  • LLM providers process data according to their own privacy policies; we recommend reviewing Groq's and Google's policies
Sensitive details (health information, location, financial data) are auto-masked before being sent to AI APIs when you have that setting enabled.

6. Your Rights & Controls

You have full control over your data at all times:

  • View: All your memories are visible in the Memory Vault
  • Edit: Modify any memory at any time
  • Pause: Temporarily stop a memory from being used
  • Delete: Remove any or all memories immediately and permanently
  • Export: Download all your memories (coming soon)
  • Retention control: Set per-room or per-memory expiry periods

Residents of the EU/EEA have additional rights under GDPR including the right to erasure, portability, and restriction of processing. Contact us to exercise these rights.

7. Data Sharing

We do not sell, rent, or trade your personal data. We share data only with:

  • LLM API providers (Groq, Google Gemini) — only chat context, only for memory detection, only over encrypted connections
  • Supabase — authentication and database hosting
  • Legal authorities — only when required by law and with proper legal process

All third-party providers are contractually bound to handle your data only for the specific purpose of providing their service to us.

8. Data Retention

Memories are kept for the duration you set (default: 6 months). You can change retention per room or per individual memory in the Privacy Center. When a memory expires or you delete it, it is permanently removed from our database with no backups retained beyond 30 days.

Account data is retained for 30 days after account deletion to allow recovery, then permanently erased.

9. Children's Privacy

Memory is not intended for use by children under 13 years of age. We do not knowingly collect personal data from children. If you believe a child has provided us with personal data, please contact us immediately and we will delete it.

10. Contact Us

For privacy questions, data requests, or to exercise your rights:

  • Email: privacy@memory.app
  • Response time: Within 48 hours for all privacy requests
