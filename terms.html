2. What Memory Does

Memory is an AI memory layer application that:

  • Detects possible memories from your AI chat conversations using LLM APIs (Groq, Gemini)
  • Lets you review, approve, edit, and delete those memories
  • Surfaces relevant memories to give AI assistants more personal context
  • Organises memories into Context Rooms (Work, Health, Personal) with separate privacy settings
Memory is a tool to enhance AI assistants, not an AI assistant itself. It does not provide medical, legal, financial, or professional advice.
